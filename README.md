# Countries Data Visualization

A small Python project that uses **pandas** and **matplotlib** to visualize population data for four countries: United States, China, India and Japan.

## What it does

- Builds a pandas DataFrame with each country's population, area (km²) and annual growth rate (%)
- Draws a **bar chart** comparing population by country
- Draws a **scatter plot** of area vs. annual growth rate

## Data

| Country       | Population    | Area (km²) | Annual growth rate (%) |
|---------------|---------------|------------|------------------------|
| United States | 331,002,651   | 9,629,091  | 0.6                    |
| China         | 1,439,323,776 | 9,640,011  | 0.4                    |
| India         | 1,380,004,385 | 3,287,263  | 1.1                    |
| Japan         | 126,476,461   | 377,972    | -0.2                   |

## Requirements

- Python 3.8+
- pandas
- matplotlib

## Installation

```bash
git clone https://github.com/Malekkk25/countries-data-visualization.git
cd countries-data-visualization
pip install pandas matplotlib
```

## Usage

```bash
python main.py
```

Two chart windows will open, one after the other.
